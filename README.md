# leaf-fluorescence-analysis
  This repository contains the Python source code for the image-analysis pipeline described in:  **Evaluating Drone-Based Versus Conventional Spraying Systems for Fungicide Application in Sugar Beet: Impacts on Canopy Penetration and Disease Dynamics**  The pipeline was developed to quantify fluorescent tracer coverage and its spatial distribution across leaf surfaces. It processes visible-light images and corresponding UV-fluorescence images and produces quadrant-specific dye coverage metrics and measures of vertical and horizontal deposition asymmetry.
